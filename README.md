# Portfolio 3D · elordenador

Portfolio jugable hecho con Three.js y Vite: una isla de vóxeles donde cada pedestal es un proyecto.

```sh
npm install
npm run dev      # desarrollo en http://localhost:5173
npm run build    # genera dist/
```

- Contenido (bio, proyectos, cubos de tecnologías): `src/data.js`
- Despliegue: importa el repo en Vercel (detecta Vite solo; `vercel.json` lo deja explícito) o ejecuta `npx vercel` en esta carpeta.
